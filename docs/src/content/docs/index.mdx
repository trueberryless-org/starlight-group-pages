## Features

<CardGrid stagger>
  <Card title="A page for every group" icon="document">
    Directories without an index page get a generated page listing their
    content as link cards.
  </Card>
  <Card title="Sidebar and pagination" icon="list-format">
    Each sidebar group links to its page, as an “Overview” item or through its
    clickable label, and the page is part of the previous and next links.
  </Card>
  <Card title="Your own introduction" icon="pencil">
    Write an index page and the plugin appends the link cards below your
    content.
  </Card>
  <Card title="Multilingual" icon="translate">
    Group pages exist in every language of your site, with translated labels
    and fallback content.
  </Card>
</CardGrid>
