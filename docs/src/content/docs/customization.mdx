Group pages are built from your sidebar configuration and the frontmatter of your pages.
See [“Group Pages”](/group-pages/#content) to learn where each part of a group page comes from.

## Add an introduction

Create an index page for the directory, e.g. `src/content/docs/guides/index.mdx`:

```mdx
---
# src/content/docs/guides/index.mdx
title: Guides
description: Step-by-step guides to get the most out of Starlight Rocket.
---

Start with the installation guide if you are new to Starlight Rocket.
```

The plugin renders your page and appends the link cards of the directory below your content.
The page supports all [frontmatter](https://starlight.astro.build/reference/frontmatter/) fields and [components](https://starlight.astro.build/components/using-components/) of a regular page.
The [Reference](/demo/reference/) demo page uses this approach.

## Change the title

Generated pages use the label of their sidebar group as title.
Change the [group `label`](https://starlight.astro.build/guides/sidebar/#groups) in your `sidebar` configuration, or [add an index page](#add-an-introduction) with the title of your choice.

Nested groups of [autogenerated links](https://starlight.astro.build/guides/sidebar/#autogenerated-links) are labeled with their directory name by Starlight, e.g. `advanced`.
To format these labels, update them in a [route middleware](https://starlight.astro.build/guides/route-data/#customizing-route-data):

```ts
// src/routeData.ts
import { defineRouteMiddleware } from "@astrojs/starlight/route-data";

export const onRequest = defineRouteMiddleware((context) => {
  titleCaseGroupLabels(context.locals.starlightRoute.sidebar);
});

function titleCaseGroupLabels(entries) {
  for (const entry of entries) {
    if (entry.type !== "group") continue;

    entry.label = entry.label.charAt(0).toUpperCase() + entry.label.slice(1);
    titleCaseGroupLabels(entry.entries);
  }
}
```

The plugin reads group labels after your middleware, so group pages, link cards and the sidebar use the same formatted label.
See [“Autogenerated Starlight sidebar”](https://desired-state.leaflet.pub/3mpvilyrxoc2f) for more ways to customize autogenerated groups, e.g. ordering directories with numeric prefixes.

## Describe the link cards

Add a [`description`](https://starlight.astro.build/reference/frontmatter/#description) to the frontmatter of a page to display it on its link card:

```md {3}
---
title: Installation
description: Install Starlight Rocket in your project.
---
```

Link cards of nested groups display the description of the group's index page, or a summary of the group's entries without one.

To change the label of a link card, change the label of the sidebar entry, e.g. with the [`sidebar.label`](https://starlight.astro.build/reference/frontmatter/#label) frontmatter field.

## Change the “Overview” label

Override the `starlightGroupPages.sidebarLink` UI string in your [translation files](https://starlight.astro.build/guides/i18n/#translate-starlights-ui):

```json
// src/content/i18n/en.json
{
  "starlightGroupPages.sidebarLink": "Introduction"
}
```

See [“Internationalization (i18n)”](/i18n/#translate-the-ui) for all UI strings and the languages provided out of the box.

## Make group labels clickable

Set the [`sidebarLink`](/configuration/#sidebarlink) option to `label`:

```js
starlightGroupPages({
  sidebarLink: "label",
});
```

The group label links to the group page and the caret next to it expands and collapses the group.
This option overrides the Starlight [`Sidebar`](/getting-started/#component-overrides) component.

## Exclude directories

Add the directories to the [`exclude`](/configuration/#exclude) option:

```js
starlightGroupPages({
  exclude: ["reference/**"],
});
```
